* **Objective:** To leverage regression algorithms to predict used car prices based on historical vehicle data, enabling data-driven decision-making for buyers and sellers.


## 🚀 Project Overview
This project builds a predictive model to estimate the selling price of used cars. By analyzing key vehicle features, the model learns the relationship between vehicle specifications (like mileage and age) and market valuation.

## 🛠 Tech Stack
* **Language:** Python 3.x
* **Data Analysis:** Pandas, NumPy
* **Machine Learning:** Scikit-learn (RandomForestRegressor)
* **Visualization:** Matplotlib
* **Version Control:** Git & GitHub

## 📊 Methodology
The workflow follows a standard Data Science lifecycle:
1. **Data Preprocessing:** Cleaning the dataset, removing irrelevant columns, and handling missing values.
2. **Feature Engineering:** Converting raw years into 'Car Age' to better reflect depreciation trends.
3. **Encoding:** Transforming categorical text data (Fuel Type, Transmission) into numerical binary format.
4. **Model Training:** Implementing a **Random Forest Regressor** to capture complex, non-linear relationships in the data.
5. **Evaluation:** Assessing performance using Mean Absolute Error (MAE) and R-squared ($R^2$) score.
